## Astroids!!! ##

This is a game of **Asteroids!!!** including tracking for scroing and player lives.

Motivation - The guided project to create the Asteroids game was nice, but I felt adding a scoring mechanism would add an enhancement to the overall gameplay. It brings an old-school game feel.

*Quick Start*
 - Players start with 3 Lives
 - Destorying a Large Asteroid grants 5 points
 - Destroying a Medium Asteroid grants 3 points
 - Destroying a Small Asteroid grants 1 point
 - Earn 1 extra life for every 100 points, upto a Max of 5 Lives


Usage:
 - 'spacebar' fires the player's weapon
 - 'a' rotates the player clockwise
 - 'd' rotates the player anticlockwise
 - 'w' moves the player forwards
 - 's' moves the player backwards
